# Регрессионные тесты плагина

Установить `pip install lupa`, запустить `python tests/test_runtime.py`. Используется Lua 5.1 и заглушки API, без клиента и зависимости от клона ElvUI. Проверяются поиск и индекс GUID, скрытие/повторное использование рамок, старый PlateGUID, ранний отсев событий, отключённые анимации, пул, прозрачность текста/иконки, один запрос времени на кадр и восстановление шрифта критического события. Эти проверки не заменяют визуальную проверку в Sirus.
